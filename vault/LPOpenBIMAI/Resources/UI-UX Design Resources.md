## Google Stitch

> [!important] MCP Integration
> Stitch tích hợp với Antigravity qua MCP server.

| Resource | Link |
|----------|------|
| **Stitch App** | [stitch.withgoogle.com](https://stitch.withgoogle.com/) |
| **API Key** | [Settings](https://stitch.withgoogle.com/settings) |
| **Skills Repo** | [GitHub](https://github.com/google-labs-code/stitch-skills) |

**MCP Config:**
```json
"mcp-stitch": {
  "serverUrl": "https://stitch.googleapis.com/mcp",
  "headers": {
    "X-Goog-Api-Key": "<YOUR_KEY>"
  }
}
```
