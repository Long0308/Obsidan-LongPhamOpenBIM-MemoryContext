# Patterns

## Architecture Patterns
- **Adapter Pattern** — Backend-agnostic interfaces (Memory Gateway)
- **Ops Model** — All mutations via explicit, serializable operations (Design Desk)
- **Canonical JSON** — Deterministic serialization for diffability
- **Local-first + Sync** — Work offline, sync when connected
- **Fallback Chain** — Primary → backup → offline graceful degradation

## Development Patterns
- **Plan → Execute → Verify** — Superpowers workflow
- **Skills-based Architecture** — Modular, composable agent capabilities
- **Knowledge Graph** — Obsidian wikilinks for relationship mapping
- **Self-evolving Memory** — Decay scoring, dedup, archival
