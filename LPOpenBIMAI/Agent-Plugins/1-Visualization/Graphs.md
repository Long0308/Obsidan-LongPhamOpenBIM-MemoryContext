# Graphs

> [!tip] Plugin
> Enhanced graph view với filters, colors theo tags.

## Quick Start
- **Open:** `Ctrl+P` → "Graphs" → "Open Graphs View"
- **Filter:** Theo tag `skill`, `memory`, `agent` để xem từng layer

## Agent Swarm Usage
- Filter theo tag `skill` → chỉ xem skill connections
- Filter theo tag `agent` → xem agent relationships
- Color-code by group (Superpowers, Backend, Design...)
