# Lovely Mindmap

> [!tip] Plugin
> Chuyển heading structure → mindmap visual tự động.

## Quick Start
- **Open:** `Ctrl+P` → "Lovely Mindmap" trên bất kỳ note nào
- Headings tự động trở thành nodes

## Agent Swarm Usage
- Mở `AGENT_SWARM.md` → mindmap = overview toàn hệ thống
- Visualize skill hierarchy theo headings
- Quick navigation giữa sections
