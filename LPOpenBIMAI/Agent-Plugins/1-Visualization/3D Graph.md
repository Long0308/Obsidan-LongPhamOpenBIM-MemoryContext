# 3D Graph

> [!tip] Plugin
> 3D visualization of vault knowledge graph with spatial navigation.

## Quick Start
- **Open:** `Ctrl+P` → "3D Graph"
- **Navigate:** Click + drag to rotate, scroll to zoom

## Agent Swarm Usage
- Xem toàn bộ vault dạng 3D xoay được
- Nhìn thấy cụm skill notes kết nối qua wikilinks
- Identify isolated nodes (notes thiếu connections)
