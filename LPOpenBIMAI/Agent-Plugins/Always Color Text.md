# Always Color Text

> [!tip] Plugin
> Text color highlighting trong notes.

## Quick Start
- **Syntax:** `<font color="red">text</font>` hoặc dùng toolbar
- **Toolbar:** Highlight button trong editor toolbar

## Agent Swarm Usage
- Color-code priority levels trong memory notes
- Highlight critical sections in guides
