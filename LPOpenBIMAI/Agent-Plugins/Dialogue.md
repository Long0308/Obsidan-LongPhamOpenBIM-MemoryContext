# Dialogue

> [!tip] Plugin
> Dialogue formatting — ghi lại conversations dạng chat bubbles.

## Quick Start
````markdown
```dialogue
left: Agent
right: User

l: Tôi sẽ phân tích yêu cầu của bạn
r: Ok, hãy bắt đầu
```
````

## Agent Swarm Usage
- Ghi lại conversations với AI trong memory notes
- Document Q&A sessions dạng visual
- Training examples cho prompts
