# Pane Relief

> [!tip] Plugin
> Per-tab navigation history — forward/back trong từng pane.

## Quick Start
- **Hotkeys:** `Ctrl+Alt+←` = back, `Ctrl+Alt+→` = forward (per-tab)
- Built-in Obsidian chỉ có global history, plugin này cho per-tab

## Agent Swarm Usage
- Navigate nhanh giữa skill notes ↔ MOC ↔ canvas
- Quay lại note vừa xem mà không mất context pane khác
