# Autocorrect Formatter

> [!tip] Plugin
> Sửa lỗi chính tả và format text tự động.

## Quick Start
- **Auto-active** — Chạy ngầm khi gõ text
- **Config:** Settings → Autocorrect Formatter

## Agent Swarm Usage
- Đảm bảo text quality trong vault notes
- Consistent formatting across skill/agent notes
