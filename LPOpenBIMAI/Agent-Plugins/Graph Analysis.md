# Graph Analysis

> [!tip] Plugin
> Phân tích centrality, clustering, shortest path trong vault graph.

## Quick Start
- **Open:** `Ctrl+P` → "Graph Analysis"
- **Metrics:** Centrality, PageRank, clustering coefficient

## Agent Swarm Usage
- Tìm skill nào là hub (nhiều connection nhất)
- Phát hiện notes bị cô lập (low centrality)
- Xác định shortest path giữa 2 skills bất kỳ
