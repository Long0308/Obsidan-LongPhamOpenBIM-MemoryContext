# Full Calendar

> [!tip] Plugin
> Calendar view tích hợp trong Obsidian.

## Quick Start
- **Open:** `Ctrl+P` → "Full Calendar: Open"
- **Events:** Tạo events từ notes với frontmatter `date:` field

## Agent Swarm Usage
- Track project timelines, sprint deadlines
- Visualize session dates từ Agent-Memory
- Plan memory decay schedules
