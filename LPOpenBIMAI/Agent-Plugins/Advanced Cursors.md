# Advanced Cursors

> [!tip] Plugin
> Multi-cursor editing nâng cao.

## Quick Start
- **Multi-cursor:** `Alt+Click` = place cursor
- **Select next:** `Ctrl+D` = select next occurrence
- **Select all:** `Ctrl+Shift+L` = select all occurrences

## Agent Swarm Usage
- Bulk edit frontmatter tags across skill notes
- Đổi tên nhanh trong nhiều notes cùng lúc
