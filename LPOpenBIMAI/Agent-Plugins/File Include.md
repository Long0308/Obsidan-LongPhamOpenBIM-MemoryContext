# File Include

> [!tip] Plugin
> Include nội dung từ file khác — mạnh hơn embed mặc định.

## Quick Start
- **Syntax:** `![[file.md]]` (built-in) nhưng plugin hỗ trợ partial include
- **Partial:** Include specific sections, line ranges

## Agent Swarm Usage
- Include snippet từ skill notes vào MOC
- Aggregate content từ nhiều notes vào 1 dashboard
