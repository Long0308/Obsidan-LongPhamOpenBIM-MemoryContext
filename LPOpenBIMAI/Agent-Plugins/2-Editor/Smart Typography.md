# Smart Typography

> [!tip] Plugin
> Tự động chuyển typography: `"text"` → "text", `--` → —, `...` → …

## Quick Start
- **Auto-active** — Tự động chuyển khi gõ
- **Config:** Settings → Smart Typography

## Agent Swarm Usage
- Format đẹp cho memory notes, documentation
- Professional typography trong system guides
