# Simple CanvaSearch

> [!tip] Plugin
> Tìm kiếm nodes trong canvas files.

## Quick Start
- **Open:** `Ctrl+P` → "CanvaSearch" khi đang ở canvas
- **Search:** Tìm theo node text, navigate trực tiếp

## Agent Swarm Usage
- Tìm node trong `Agent-Swarm.canvas` (33+ nodes)
- Quick-find skills/agents trong visual map
- Navigate canvas lớn efficiently
