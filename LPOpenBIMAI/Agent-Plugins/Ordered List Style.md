# Ordered List Style

> [!tip] Plugin
> Custom numbering styles: a, b, c / i, ii, iii / roman numerals.

## Quick Start
- **Activate:** Thêm `cssclasses: list-style-alpha` vào frontmatter
- **Styles:** `list-style-alpha`, `list-style-roman`, `list-style-decimal`

## Agent Swarm Usage
- Custom numbering trong task lists, checklists
- Professional formatting cho documentation
