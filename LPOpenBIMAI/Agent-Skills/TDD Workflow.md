# TDD Workflow

> [!abstract] Skill
> Test-Driven Development workflow principles. RED-GREEN-REFACTOR cycle for building reliable software.

## Triggers
`TDD, red green refactor, test first, test driven`

## Key Concepts
- **RED** — Write a failing test that defines desired behavior
- **GREEN** — Write minimum code to make the test pass
- **REFACTOR** — Clean up code while keeping tests green
- **Cycle speed** — Keep cycles short (minutes, not hours)
- **Design benefit** — TDD drives better API design through usage-first thinking
