# Testing Patterns

> [!abstract] Skill
> Testing patterns and principles. Unit, integration, mocking strategies. Test pyramid, AAA pattern.

## Triggers
`testing, unit test, integration test, mock, stub, spy, test pyramid, AAA`

## Key Concepts
- **Test pyramid** — Unit (70%) > Integration (20%) > E2E (10%)
- **AAA Pattern** — Arrange, Act, Assert structure
- **Mocking** — When to mock vs stub vs spy, dependency injection
- **Coverage** — Line vs branch vs path, meaningful coverage targets
- **Fixtures** — Factory patterns, test data builders, seeding
