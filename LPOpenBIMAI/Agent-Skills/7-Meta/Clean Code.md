# Clean Code

> [!abstract] Skill
> Pragmatic coding standards. Concise, direct, no over-engineering, self-documenting code. Applied globally to ALL code output.

## Triggers
`clean code, coding standards, naming, refactor, code quality`

> [!important]
> **Always-on skill** — Applied automatically as TIER 0 in GEMINI.md. No manual activation needed.

## Key Concepts
- **Self-documenting** — Clear naming > comments, intent-revealing code
- **YAGNI** — Don't build what you don't need yet
- **Single Responsibility** — One function = one job
- **No dead code** — Remove unused imports, variables, functions
- **Error handling** — Explicit, not swallowed; meaningful messages
