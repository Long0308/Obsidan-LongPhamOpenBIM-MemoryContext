# Frontend Design

> [!abstract] Skill
> Design thinking and decision-making for web UI. Components, layouts, color schemes, typography, creating aesthetic interfaces.

## Triggers
`thiết kế web, web design, component, layout, color scheme, typography, CSS`

## Key Concepts
- **Design system** — Tokens, spacing scale, color palette architecture
- **Component design** — Atomic design, composition patterns
- **Typography** — Font pairing, scale, readability hierarchy
- **Color theory** — HSL-based palettes, contrast ratios, dark mode
- **Layout** — Grid systems, responsive breakpoints, whitespace
