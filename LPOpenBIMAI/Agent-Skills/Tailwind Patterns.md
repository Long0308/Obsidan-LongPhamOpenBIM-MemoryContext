# Tailwind Patterns

> [!abstract] Skill
> Tailwind CSS v4 principles. CSS-first configuration, container queries, modern patterns, design token architecture.

## Key Concepts
- **v4 CSS-first config** — `@theme` directive, no more `tailwind.config.js`
- **Container queries** — `@container` responsive patterns
- **Design tokens** — CSS custom properties as single source of truth
- **Dark mode** — `prefers-color-scheme`, manual toggle patterns
- **Performance** — PurgeCSS, JIT compilation, bundle optimization
