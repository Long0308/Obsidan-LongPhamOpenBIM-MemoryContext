# Behavioral Modes

> [!abstract] Skill
> AI operational modes defining behavior based on task type. Brainstorm, implement, debug, review, teach, ship, orchestrate.

## Triggers
`mode, behavior, brainstorm mode, debug mode, review mode, teach mode`

## Key Concepts
- **Brainstorm mode** — Exploratory, many options, no commitment
- **Implement mode** — Focused execution, follow the plan
- **Debug mode** — Systematic investigation, hypothesis-test cycles
- **Review mode** — Critical eye, quality gates, feedback
- **Teach mode** — Explain concepts, show examples, patient
- **Ship mode** — Final checks, deployment prep, verification
- **Orchestrate mode** — Multi-agent coordination, task decomposition
