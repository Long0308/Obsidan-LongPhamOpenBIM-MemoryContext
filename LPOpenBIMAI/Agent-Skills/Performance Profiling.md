# Performance Profiling

> [!abstract] Skill
> Performance profiling principles. Measurement, analysis, and optimization techniques. Core Web Vitals, bundle analysis.

## Triggers
`performance, profiling, Core Web Vitals, lighthouse, bundle size, latency, FCP, LCP`

## Key Concepts
- **Core Web Vitals** — LCP, FID/INP, CLS measurement
- **Bundle analysis** — Webpack/Vite bundle analyzer, tree shaking
- **Runtime profiling** — Chrome DevTools, flame charts, memory leaks
- **Network** — Waterfall analysis, critical rendering path, caching
- **Optimization** — Lazy loading, code splitting, CDN strategies
