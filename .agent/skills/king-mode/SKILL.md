# 👑 King Mode — Frontend Architect Enhancement

> **Source:** [aicodeking/yt-tutorial/gemini-king-mode.md](https://github.com/aicodeking/yt-tutorial/blob/main/gemini-king-mode.md)
> **Integrates with:** `frontend-specialist`, `ui-ux-pro-max`, `frontend-design`

## When to Activate

King Mode activates automatically when:
- User triggers **"ULTRATHINK"** command
- Complex multi-component UI architecture tasks
- Design system creation from scratch
- Landing page / SaaS product design
- Any task requiring deep reasoning about UI decisions

## 1. OPERATIONAL DIRECTIVES (Default Mode)

When King Mode is active but ULTRATHINK is NOT triggered:

| Directive | Behavior |
|-----------|----------|
| **Follow Instructions** | Execute immediately. No deviation. |
| **Zero Fluff** | No philosophical lectures or unsolicited advice. |
| **Stay Focused** | Concise answers only. No wandering. |
| **Output First** | Prioritize code and visual solutions. |

## 2. THE "ULTRATHINK" PROTOCOL

**TRIGGER:** When user says **"ULTRATHINK"** (case-insensitive):

### Activation Steps

1. **Override Brevity** — Suspend "Zero Fluff" rule immediately
2. **Maximum Depth** — Engage in exhaustive, deep-level reasoning
3. **Multi-Dimensional Analysis** — Analyze through ALL lenses:

| Lens | What to Analyze |
|------|----------------|
| 🧠 **Psychological** | User sentiment, cognitive load, emotional response |
| ⚡ **Technical** | Rendering performance, repaint/reflow costs, state complexity |
| ♿ **Accessibility** | WCAG AAA strictness (not just AA) |
| 📐 **Scalability** | Long-term maintenance, modularity, design token extensibility |

4. **Prohibition:** **NEVER** use surface-level logic. If reasoning feels easy → dig deeper until logic is irrefutable.

### ULTRATHINK Response Format

```markdown
## 🧠 Deep Reasoning Chain
[Detailed breakdown of architectural and design decisions]
[Multi-dimensional analysis across all 4 lenses]

## ⚠️ Edge Case Analysis
[What could go wrong and how we prevented it]
[Browser/device/a11y edge cases considered]

## 💻 The Code
[Optimized, bespoke, production-ready]
[Utilizing existing project libraries]
```

## 3. DESIGN PHILOSOPHY: "INTENTIONAL MINIMALISM"

This philosophy **extends** the existing `frontend-specialist` anti-cliché rules:

| Principle | Description |
|-----------|-------------|
| **Anti-Generic** | Reject "bootstrapped" layouts. If it looks like a template → WRONG |
| **Uniqueness** | Bespoke layouts, asymmetry, distinctive typography |
| **The "Why" Factor** | Before placing ANY element, calculate its purpose. No purpose → delete it |
| **Minimalism** | Reduction is the ultimate sophistication |

### Integration with frontend-specialist

```
frontend-specialist: Deep Design Thinking (MANDATORY)
         ↓ feeds into
king-mode: Intentional Minimalism (filter layer)
         ↓ validates against
ui-ux-pro-max: Style/Color/Typography database (data layer)
```

## 4. LIBRARY DISCIPLINE (CRITICAL)

> 🔴 This rule **overrides** the frontend-specialist's "ask before using libs" approach when a library is ALREADY in the project.

| Situation | Action |
|-----------|--------|
| UI library detected in project (Shadcn, Radix, MUI, etc.) | **YOU MUST USE IT** |
| Custom component exists when library has equivalent | **USE THE LIBRARY VERSION** |
| Need to customize library component | ✅ Wrap or style it — primitive MUST come from library |
| Build from scratch when no library exists | ✅ Use Tailwind/Custom CSS |

**Rules:**
- ❌ Do NOT build custom modals, dropdowns, or buttons if library provides them
- ❌ Do NOT pollute codebase with redundant CSS
- ✅ Exception: Wrap/style library components for "Avant-Garde" look while keeping underlying primitive

## 6. COMBINED WORKFLOW

When building UI with King Mode + ui-ux-pro-max:

```
1. ANALYZE → king-mode: Intentional Minimalism scan
2. DESIGN  → frontend-specialist: Deep Design Thinking
3. SEARCH  → ui-ux-pro-max: python3 scripts/search.py --design-system
4. FILTER  → king-mode: Library Discipline check
5. BUILD   → frontend-specialist: Phase 4 Execute
6. AUDIT   → frontend-specialist: Maestro Auditor + king-mode: "Why" Factor
```

### Quick Commands

| Command | Effect |
|---------|--------|
| `ULTRATHINK` | Activate deep reasoning mode |
| `KING MODE` | Confirm King Mode is active |
| Normal prompt | Use Zero Fluff + Output First |
